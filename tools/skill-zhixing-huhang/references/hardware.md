# 硬件事实（与 PROJECT.md 有出入处以此为准）

所有结论均来自数据手册 / 协议文档 / 实测，未经验证的会标注「待确认」。

## 毫米波雷达：MS60-1211S80M（人存版）

- **型号**：`MS60-1211S80M`（人存版，PROJECT.md 误写为 MS60-1211S80）。核心芯片是隔空科技 **AT6010**，60GHz，1T2R，5GHz 带宽。
- **波特率**：**115200**（不是手册默认的 921600，本机模块已切换到 115200）。
- **帧格式**：
  - 命令 `0x58`：`[HEAD][CMD][LEN][参数...][校验低][校验高]`，校验 = 前面所有字节之和（16 位小端）。
  - 回复 `0x59`：同上。
  - 主动上报 `0x5A`：`[HEAD][LEN][TYPE][字段...][8位校验]`，仅检测到目标才发。
- **数据获取**：模块是从机，不发数据，靠 **0x30 命令轮询**取检测信息（距离 mm / 角度 / 置信度 / 帧号）。
- **关键限制**：`velo_val` 字段「预留」，**无速度输出**。`rb_conf<12` 距离可能不准、`angle_conf<8` 角度可能不准（模块自带的置信度提示，应用逻辑应当使用）。
- **OUT 引脚**：只是 1-bit 存在信号（有人高/无人低，或 PWM），**不含数据**，别想从它读信息。
- **接线**（radar-debug 工程）：ESP32 `TX=GPIO14 → 雷达RX`、`RX=GPIO21 ← 雷达TX`、VCC=3V3、GND 共地。
- 命令表与逆向结果：`Technical Support Document/雷达AT6010_命令表(从上位机airhost.dll提取).md`

## IMU：HW-991（芯片 BMI270）

- HW-991 模组的传感器芯片是 **BMI270**（不是资料里某些地方含糊的写法）。
- **上电必须先上传 8192 字节的官方配置块**，之后才会输出有效数据。参考 `imu-debug/components/imu_bmi270/`（已跑通）。

## 摄像头：OV2640（Freenove 板）

- 传感器 OV2640（PID 0x26），镜头 M12 可换，原厂镜头视角约 62°。
- **引脚与 ESP32-S3-EYE 完全一致**（Freenove 自家 Arduino 例程用的就是 `CAMERA_MODEL_ESP32S3_EYE`）：
  `XCLK=15 PCLK=13 VSYNC=6 HREF=7 D0..D7=11,9,8,10,12,18,17,16 SIOD=4 SIOC=5`
- **ESP-IDF esp_video 驱动有两个已知坑**（详见 debug-log.md）：
  1. RGB565（非 JPEG）模式下 DVP 每帧只收到 1/8 数据。
  2. SCCB 用 400kHz 时，写 JPEG 格式寄存器表会 I2C 超时。
  - 解决办法：**摄像头输出用 JPEG + SCCB 降到 100kHz**。

## 板子

- 两块都是 **ESP32-S3-N16R8**（16MB Flash / 8MB OPI PSRAM）：一块带摄像头座 + microSD，一块最小板。
