# 智行护航：果园小型农机作业与转场全程主动安全头盔（技术方案 v2）

> 版本：v2.0 ｜ 日期：2026-10-09 ｜ 面向对象：评委、队友、指导老师（人读版）

## 0. 一句话定位

面向果园小型农机的**作业与转场全过程**主动安全头盔——以毫米波雷达、视觉与 IMU 多模态融合，对农机**后方与侧向盲区**进行检测、识别与分级预警。

## 1. 背景与痛点

果园小型农机（如履带田园管理机、喷雾机、运输车）作业速度仅 1~6 km/h，驾驶员要频繁抬头观察枝叶、扭头观察机具，后方与侧向是天然的视野盲区；田间还有工人、儿童、动物，倒车和转弯都存在风险。

更隐蔽的痛点发生在**转场**：农机以 20~30 km/h 上乡村公路转移地块，后方汽车、摩托车快速超越，而这类农机多数没有后视与盲区监测能力，尾部事故高发。转场安全本来就是农业农村部农机安全生产宣传的重点。

**问题的本质**：农机驾驶员的注意力与视野是稀缺资源，而农机没有像汽车那样的盲区监测手段。

## 2. 总体方案

一套可穿戴头盔，覆盖驾驶员「机上驾驶 + 离机作业」两种状态。头顶承载板集成两块 ESP32-S3，四周分布三颗毫米波雷达与摄像头。

```text
                  头顶承载板（ESP32-S3 ×2 · IMU · 电源 · 按键 · 蜂鸣器）
                    │                │                │
             后向 60G(BSD)     左 60G(人存)      右 60G(人存)
                    │                                │
            后视摄像头(OV2640)                左/右/后 三个振动马达
```

| 模块 | 数量 | 作用 |
|---|---|---|
| ESP32-S3 开发板 | 2 | 感知融合 + 视觉推理 |
| 60G 毫米波雷达（BSD 版）| 1 | 后方测距测速（6~90 km/h）|
| 60G 毫米波雷达（人存版）| 2 | 左右存在检测（慢速/静止目标）|
| OV2640 摄像头 | 1 | 后视目标分类 |
| BMI270 IMU | 1 | 本体运动补偿 + 头姿（低头检测）|
| 振动马达 | 3 | 左/右/后 方向性触觉告警 |
| 有源蜂鸣器 | 1 | 声音告警 |

## 3. 双场景自适应

| 维度 | 果园作业（主场景）| 转场上路（扩展场景）|
|---|---|---|
| 速度 | 1~6 km/h | 20~30 km/h |
| 主要威胁 | 行人、工人、儿童、慢速农机 | 高速超越的汽车、摩托车 |
| 主力传感器 | 人存版雷达（存在检测）| BSD 雷达（测距测速）+ 摄像头 |
| 告警策略 | 存在 + 接近提醒 | 高速接近分级告警 |

## 4. 感知与融合分工

| 传感器 | 职责 |
|---|---|
| 雷达 | 全天候「有没有、多远、多快」|
| 摄像头 | 「是什么」（5 类目标）|
| IMU | 本体运动补偿 + 头姿 |

融合链路：**雷达触发 → 视觉确认类别 → IMU 门控 → 分级告警**。雷达是第一发现者，视觉负责确认，IMU 负责判断驾驶员是否低头。

## 5. 告警分级

| 级别 | 触发条件 | 输出 |
|---|---|---|
| L1 | 后方有目标接近 | 后马达振动 + 短蜂鸣 |
| L2 | 摄像头确认目标类别 | 对应方向马达 + 蜂鸣 |
| L3 | 低头 >35° 持续 1.5s（无论有无目标）| 三马达同时振 + 长鸣 |
| L4 | 低头 + 目标接近 | 三马达连续振 + 连续蜂鸣 |

农机作业噪声大，**触觉（振动）是主告警通道**，蜂鸣器为辅助。

## 6. 创新点

1. **可穿戴、随人走**：覆盖「机上驾驶 + 离机作业」两种状态，是车装盲区雷达覆盖不到的场景。
2. **双场景自适应**：田间低速与转场高速两套感知与告警策略自动切换。
3. **端侧多模态融合**：两片 ESP32-S3 完成雷达/视觉/IMU 融合，整机几瓦功耗，适配农机开放环境。
4. **预测式主动安全**：BSD 雷达直测来车速度 + 视觉确认 + 头姿门控，而不是简单测距报警。
5. **模块化设计**：全部感知与驱动采用现成模块，首次打样即可上电工作，迭代成本低。

## 7. 预期指标

| 指标 | 目标 |
|---|---|
| 后方车辆检测 | 0.5~40 m，速度 6~90 km/h |
| 左右行人检测 | 0.5~15 m |
| 视觉目标类别 | 人 / 自行车 / 摩托车 / 轿车 / 卡车，共 5 类 |
| 端侧推理 | ≥2 FPS（INT8，224×224）|
| 低头告警延迟 | ≤1.5 s |
| 整机功耗 | <5 W |

## 8. 进度与计划（倒计时约 40 天）

1. 方案定稿（本版）
2. 原理图 / PCB 打样（1~2 周）
3. 视觉模型 5 类训练与量化（与打样并行）
4. 整机联调、田间与道路实测
5. 答辩材料与演示

## 9. 风险与应对

| 风险 | 应对 |
|---|---|
| 三颗 60G 同处头盔可能互扰 | 分朝向摆放；台架实测后再定时分 |
| BSD 版协议与人存版有差异 | 逻辑分析仪对齐命令表后统一固件 |
| 后置摄像头排线过长花屏 | 相机板后置或加长屏蔽 FPC，实测临界长度 |
| 低头误报 | 实戴标定阈值，连续判定去抖 |
| 模型训练时间紧 | 训练与打样并行；类别控制在 5 类 |
